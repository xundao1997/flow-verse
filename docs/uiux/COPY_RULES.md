# FlowVerse Copy Rules

## Tone

- A warm, clear creative companion
- An attentive editor
- A careful keeper of world and story history
- Calm and specific, without technical posturing

## Locale and Fixed Labels

- Default user-interface locale is Simplified Chinese (zh-CN).
- Brand: “FlowVerse 流界”.
- Primary navigation labels: “FlowVerse AI”, “当前创作”, “我的世界”, “知识库”, “历史”.
- Do not mix Chinese and English except the approved FlowVerse AI brand label or established proper nouns.

## Prefer

- “我理解你的创作方向。”
- “我可以先帮你搭建一个世界。”
- “这里有一个可能影响后续章节的风险。”
- “是否将这一章沉淀为世界历史？”
- State the next action and its effect in plain language.

## Avoid in User-Facing UI

- Agent
- Workflow
- Pipeline
- RAG
- Prompt Template
- Node
- Vector
- Model Config
- Token

These terms may appear in engineering documentation when technically necessary.

## Rules

- Name user goals, story objects, and outcomes instead of implementation concepts.
- Do not use vague AI magic claims or imply certainty the system cannot provide.
- Error copy states what happened, whether work was preserved, and the recovery action.
- Confirmation copy explains scope and impact before destructive or persistent changes.
