# FlowVerse Product Positioning

## Decision Status

- Normative product direction for FlowVerse's first release, V1.
- V1 is an initial build, not a redesign, migration, upgrade, or continuation of any v0.x product.
- Product direction, UIUX principles, and acceptance standards are human-owned constraints.
- AI may implement and validate them but must not redefine them without explicit approval.

## One Sentence

FlowVerse 流界 is an AI creative companion that understands creative intent through conversation, generates a dedicated workspace for complex work, and helps authors build worlds, write chapters, and preserve story history over time.

## Product Is

- An AI creative companion
- A long-form writing assistant
- A world-building assistant
- A creative-context manager
- A long-term story memory system

## Product Is Not

- An administration console
- A workflow editor
- An Agent configuration platform
- A Prompt toolbox
- A novel analytics Dashboard
- A Dify-like application orchestrator

## Core Experience

- First impression: “I can directly tell AI what I want to create.”
- Never require users to understand system modules before they can begin.
- Let simple requests finish in conversation.
- Generate a focused creative workspace only when the task needs sustained context or artifacts.
- Let completed work accumulate as reusable world and story assets.
