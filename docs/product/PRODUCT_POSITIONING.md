## One Sentence

FlowVerse 流界 is a multi-model, multi-Agent novel creation and real-operation loop workbench that keeps AI candidates, human-confirmed content, external release evidence, feedback, analysis, decisions, and successive iterations traceable.

## Product Is

- A desktop-first long-form novel creation workbench
- A governed multi-model and business-role collaboration system
- A candidate, Review, formal-content, memory, and immutable-version system
- A manual external-release, evidence, feedback, analysis, and human-decision loop
- A task and Cycle history system with explicit recovery, cost, policy, and audit states

## Product Is Not

- A one-shot text generator or generic chatbot homepage
- An automated publishing, platform-login, scraping, or growth-guarantee product
- A free-form Agent studio, Prompt toolbox, custom DAG editor, or general Workflow Builder
- A multi-user/team product, cross-task knowledge graph, BYOK platform, or full mobile editor in MVP
- A system that lets AI or administrators silently turn candidates into formal user facts

## Cumulative Release Roadmap

| Release | First complete product result | Cumulative boundary |
|---|---|---|
| V1.0 — 小说场景 | Establish a novel task, confirm a `CreationBaseline`, use governed AI candidates and human Review to create, recover, and export the first immutable formal novel snapshot | No actual release or Cycle is required; initial AI-assisted creation is in scope |
| V1.1 — AI 内容分析与运营复盘 | Extend the task with a confirmed `OperationValidationBaseline`, one manual real external release, evidence and feedback, an AI analysis candidate, a user-confirmed formal analysis, and a formal human decision | “Continue observing” is a separate non-decision action and never closes the Cycle; V1.0 remains fully available |
| V1.2 — AI 内容创作与运营闭环效果 | Turn a formal human decision into the next AI content or packaging candidate, confirm the actual change, complete the adjacent valid release, compare Cycle N/N+1, report individual value, and retain the following Cycle N+2 path (Cycle 3 on the normal path) | This is the cumulative completion point for the approved PRD v1.1 full-loop contract; it never claims causality or market validation |
| V2.0 — 金融研究 | Add governed analysis and review for stocks, funds, and futures behind a separate financial-domain product and acceptance boundary | Direction is confirmed, but detailed business scope requires a separate approved PRD/acceptance baseline and does not expand V1 acceptance |

Release numbers identify product-delivery capability, not novel content snapshots, packaging versions, or Cycle numbers. Each later V1 release must preserve and regress every earlier due contract.

## Core Experience

- Enter through the work home, where one shared Bot capability and deterministic task entry points remain visible together.
- Confirm and freeze the V1.0 `CreationBaseline` before the first formal creation batch; complete the V1.1 `OperationValidationBaseline` before an actual release can start a Cycle.
- Create story settings, characters, outline, and chapters as candidates; Review and human confirmation create immutable formal snapshots.
- Confirm a manual external release before atomically starting a Cycle.
- Capture real feedback, confirm formal analysis, and require a human decision before normally closing the Cycle.
- Carry the decision into the next actual content or packaging change and continue through Cycle N.
- Validate the MVP mechanism with one default user, one real novel, one real platform, and two consecutive valid Cycles.
